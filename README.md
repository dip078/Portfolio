# Developer Portfolio

## Run locally

```bash
npm install
npm run dev
```

Edit `src/App.jsx` to replace placeholder name, email, social links, and project details. Put your real resume at `public/resume.pdf` to enable the resume button.

## Production build

```bash
npm run build
npm run preview
```

The contact button currently opens the visitor's email app; a working submission form can be added in the next step.
